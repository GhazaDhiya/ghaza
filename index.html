Penjelasan hasil dan rentang data

Input distandardisasi sebelum dihitung melalui fungsi Gaussian dan konsekuen model. Hasil fraksi dikonversi menjadi persen. Aplikasi mempertahankan pembatasan nilai prediksi minimum 0% dari versi sebelumnya. RMSE dan MAE merupakan ringkasan galat pada data uji, bukan interval kepastian untuk setiap prediksi.

Pemeriksaan rentang dilakukan pada masing-masing fitur dari 45 observasi. Prediksi skenario merupakan keluaran model, dan perlu ditelaah bersama kondisi lapangan sebelum memilih rancangan.

Alur penggunaan

  1. Masukkan parameter lapanganIsi enam input sesuai definisi dan skala yang digunakan pada data penelitian.
  2. Telaah hasil prediksiPeriksa estimasi overbreak serta posisi input terhadap rentang data teramati.
  3. Bandingkan alternatifSimpan skenario, ubah parameter yang relevan, lalu bandingkan prediksinya.
  4. Bawa ke evaluasi desainEkspor hasil untuk ditinjau bersama target kemajuan dan kondisi geoteknik.
